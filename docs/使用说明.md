# 短剧生产工作台 · 使用说明

输入**一段需求**,即可由多 Agent 流水线产出一份面向中国国内市场、为 Ashley(爱室丽)家具带货的**竖屏短剧制作方案**(抖音 / 快手 / 红果短剧,9:16)。本文配截图讲清如何本地运行、每个页面怎么用。

> 截图取自真实运行(Vertex Gemini 2.5-flash + Imagen,Postgres 历史持久化)。文中所有图片在 [`docs/screenshots/`](screenshots/)。

---

## 一、本地启动

**前置**:Go 1.23+、Node 18+;历史持久化需要一个 Postgres(可选)。

### 1. 后端(默认 8080)

```bash
cd backend
make server            # 无 Key:演示模式(返回固定示例方案)
```

接入**真实大模型**时按优先级择一(`llm.FromEnv`):

```bash
# ① Vertex AI(支持文本 + Imagen 出图)
export VERTEX_CREDENTIALS_FILE=/path/to/vertex-sa.json
export VERTEX_LOCATION=us-central1
export GEMINI_MODEL=gemini-2.5-flash
# ② 或 AI Studio(仅文本)
export GEMINI_API_KEY=your-key
# 历史持久化(可选):指向 Postgres
export DATABASE_URL="postgres://drama:drama@localhost:5432/drama?sslmode=disable"
make server
```

> 本机示例用的是 `backend/run-dev.sh`(gitignored):内置 Vertex 凭证、`PORT=8080`、`DATABASE_URL`。

### 2. 前端(默认 3000)

```bash
cd frontend
npm install
npm run dev            # http://localhost:3000,默认调用 :8080 后端
```

后端不在 8080 时,用 `NEXT_PUBLIC_API` 指向它(或写进 `frontend/.env.local`)。

### 3. 一键容器部署(可选)

```bash
make deploy            # docker compose 起 postgres + 后端 + 前端
```

## 三、四步向导

### 第 1 步 · 填写需求

用**一段话**写清:题材 / 套路 · 爽点 · Ashley 植入重点,再设集数、单集秒数。

- **提示词助手**:点「套用模板」、点标签(题材套路 / 爽点引擎 / Ashley 植入)即追加到需求里;或点「✨ AI 扩写 / 优化」把粗略想法补全成完整需求。
- **参考素材(可选)**:6 张预设家居图 + 本地上传(≤3 张)。素材会喂给「AI 扩写」与「生成」,影响立意 / 植入 / 分镜。

填好后点 **「▸ Action · 生成方案」**。

![填写需求](screenshots/02-step1-brief.png)

### 第 2 步 · 选立意

AI 围绕你的需求给出 **3 个显著不同的方向**(不同梗概、爽点引擎、基调、核心冲突)。选定一个,可在下方「微调所选方向」**就地修改**其关键字段,再点 **「确认并生成 →」**。

![选立意](screenshots/03-step2-concepts.png)

### 第 3 步 · 生成中

按选定立意,从「剧集圣经」往下跑完整流水线。时间线**实时**展示每个阶段(立意 → 圣经 → 人物 → 分集 → 植入 → 英雄分镜 → 制作分发 → 概念图),每段完成即打勾;可展开看该段原始输出。

> 分集阶段有一道确定性「节奏闸门」:每集必须有钩子 + 结尾悬念、爽点密度 ≥ 60%,不达标会自动重写一次。

![生成中](screenshots/04-step3-pipeline.png)

### 第 4 步 · 制作方案

产出一份 **8 区块**的完整方案,可直接交付编剧室 / 剧组:

| 区块 | 内容 |
|---|---|
| 分镜·概念图 | Vertex Imagen 生成的 9:16 系列海报 + 英雄场景图 |
| 01 立意 | 梗概、主题、受众、基调、爽点引擎、核心冲突 |
| 02 剧集圣经 | 剧名、题材标签、集数/时长、平台、品牌植入主线 |
| 03 人物 | 主角/反派/爱情线等小传、弧光、关系 |
| 04 分集 | 每集梗概、节拍、黄金 3 秒钩子、结尾悬念、爽点 |
| 05 Ashley 植入 | 哪集哪场景植入哪个 SKU、踩哪个情绪节点、CTA 时机 |
| 06 英雄场景 | 高爽点剧集的完整分镜表 + 台词 |
| 07 制作 | 画幅、预算档、镜头数、卡司、场景、家具道具 |
| 08 分发 | CTA 文案、挂链位置、话题标签 |

- 每个区块右上角有 **「✎ 编辑」**(就地改字段)和 **「↻ 重生成本段」**(带一句额外要求,只重跑这一段)。
- 顶部可一键导出 **JSON / Markdown**;点「＋ 新方案」重新开始。
- 完整方案在 `/api/generate` 跑完后会**自动存入历史**(配置了 DATABASE_URL 时)。

![制作方案](screenshots/05-step4-plan.png)

## 四、历史方案

点右上角 **「历史」** 查看过往生成的全部方案。

### 列表

每张卡片显示剧名、集数、需求摘要、时间;悬停可**删除**。点卡片进入详情。

![历史列表](screenshots/06-history-list.png)

### 详情:逐区块编辑 + 自动存回

历史详情和方案页一样,每个区块可**单独**「✎ 编辑」或「↻ 重生成本段」。

- **点「✓ 完成」即自动存回历史**(覆盖原记录),右上角状态会从 `● 编辑后点「完成」即自动存回` → `保存中…` → `✓ 已保存`。
- 「↻ 重生成本段」跑完也自动存回。
- 有未存改动时点「← 返回列表」会二次确认。

![历史详情](screenshots/07-history-detail.png)

点某区块「✎ 编辑」后,该区块字段变成可输入框(其它区块不受影响),改完点「✓ 完成」即落库:

![区块编辑](screenshots/08-history-edit.png)

## 五、说明 / 常见问题

- **无 Key 也能用**:不配任何凭证时走内置演示(返回固定示例方案,无概念图),用于体验链路。
- **真实生成**:配 Vertex(支持出图)或 AI Studio(仅文本)后即走真实大模型;上图正是 Vertex 真实生成结果。
- **历史持久化**:需配 `DATABASE_URL`(Postgres);未配时生成照常工作,历史列表为空。
- **概念图**:仅 Vertex 模式经 Imagen 出图;其它模式自动跳过,文字方案照常完整。
- **编辑 / 重生成 的落库**:
  - 「生成页(第 4 步)」的编辑是即时草稿,不单独落库(整份方案在生成时已自动入库)。
  - 「历史详情页」的编辑 / 重生成**会**在点「完成」/ 跑完后自动存回对应记录。
- **默认账号 admin/admin、CORS `*`** 是本地便利设置,上公网前请加固。
