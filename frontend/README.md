# Frontend — Ashley Short-Drama Workbench

Next.js + Tailwind UI for the workbench. It posts a brief to the Go backend and
renders the streamed (SSE) stage timeline and final production plan.

See the [root README](../README.md) for architecture, business rationale, and
run instructions (`npm install && npm run dev`; set `NEXT_PUBLIC_API` if the
backend is not on `http://localhost:8080`).
